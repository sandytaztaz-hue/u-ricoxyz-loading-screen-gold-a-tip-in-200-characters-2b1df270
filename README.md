One loading-screen tip for stressed developers and AI coding agents: while
the build loads, the agent is googling the exact error message the developer
already pasted into another tab.


## The tip

> Tip: while this loads, your agent is googling your exact error message — the one you pasted into another tab 20 seconds ago.

## Run

```sh
python3 main.py
```

The program writes the tip to `/output/entry.txt` and prints it to stdout.
The output is identical on every run.
